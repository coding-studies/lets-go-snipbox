== Intro

Started the project with go 1.23.1.

== Run the web application

Providing the database authentication details is necessary.
This is currently done through the shell's environment variables:

[source,bash]
----
$ PG_HOST=localhost \
    PG_USER=user \
    PG_PASS=pass \
    PG_DBNAME=dbname \
    go run ./cmd/web \
    -addr=':4000'
----

Or with gow:

[source,bash]
----
$ PG_HOST=localhost \
    PG_USER=user \
    PG_PASS=pass \
    PG_DBNAME=dbname \
    $GOPATH/bin/gow -e=go,html run ./cmd/web \
    -addr=':4000'
----

== PostgreSQL database

The PostgreSQL database is provided through docker.
Start it with these commands:

[source,bash]
----
$ cd ./docker
$ docker compose up
----

On another shell session, connect to the database:

[source,bash]
----
$ docker exec -it pgsnipbox psql -U dev -d snipbox_dev
----
